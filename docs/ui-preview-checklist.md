# UI 开发预览检查清单

本清单区分源码／GPUI test context 回归与真实 macOS 键鼠视觉验收。当前按用户要求暂停全部手机及 USB 访问；不能以此清单或离线结果宣布手机传输已通过。

## 安全启动

```bash
# 已构建的独立二进制；明确禁止加载设备后端或启动 worker
./target/debug/app-gpui --local-only

# 本地 app bundle 也必须通过实际可执行文件传入该参数；今晚不经 Finder 无参数启动
"/absolute/path/to/MTP-Native.app/Contents/MacOS/app-gpui" --local-only
```

- 界面明确显示“仅本地交互预览”；连接及上传／下载不可执行。
- 即使同时存在 `MTP_KALAM_LIBRARY`、`--library` 或 bundle 内 native 库，local-only 仍优先。
- 不执行任何真实 probe / acceptance / inspect 命令；历史失败报告、快照、journal 均原样保留。

## 导航与选择

1. 本地列表可滚动，单击选中与面板焦点具有不同、清晰的反馈。
2. 上下键、Home、End 只在焦点面板选择当前快照条目；空列表安全无操作，选择滚动到可见范围。
3. Enter 只进入真实目录，普通文件不触发上传或下载。
4. Tab 切换面板；Esc 先关闭右键菜单，否则只清除当前焦点面板的选择。
5. 向上／根目录／刷新与面包屑走捕获的原始路径或引用，不从显示文字重建 I/O 路径。
6. 显示为替代字符的 Unix 非 UTF-8 名称不能借复制为 UTF-8 字符串而改变真实路径；不可无损复制的操作应禁用。
7. 目录、普通文件、symlink、设备未配置、加载中、空列表和错误状态有各自准确提示。

## 右键与旧回调

- 目录提供导航；普通文件传输仍受实际方向能力和预检限制。
- 不提供远端删除、重命名、Replace、递归目录传输或伪 USB Cancel。
- 菜单捕获原身份、快照／会话 epoch 和单次菜单 ticket；旧菜单回调不得作用于后来打开的菜单，也不得关闭新菜单。
- 存储按钮捕获 StorageId 与渲染 epoch；重连或重新排序后，旧按钮不能按旧 index 选择另一个存储。
- 这些旧回调场景主要由离线测试构造，不冒充已在系统键鼠中复现。

## 传输展示与证据

- 提交前明确显示源与当前目标；下载目标是本地当前目录，不是选中的子目录。
- 上传 KeepBoth 会使用随机最终名；下载 Skip 与 KeepBoth 解释清楚，Skip 不算成功。
- 禁用按钮没有可执行 handler；无效点击只产生独立预检提示，不覆盖已完成 receipt、实际路径、journal 或捕获目标。
- 新任务可将上一结果归档为有界的展示历史；不保留可再次执行的 RemoteRef／TransferPlan，不扫描磁盘或自动清理。
- 展开任务区可阅读完整路径与 journal；复制只允许无损 UTF-8，不把显示路径作为操作权限。
- RequiresReview 是独立、显著的结果未知告警。人工确认只解除交互屏障并等待手动新连接，不改变旧任务为成功，不重试、不删除、不自动连接。
- 传输进行中远端导航冻结，本地浏览可继续；终态按独立任务 ID 接受，不因本地目录变化而丢弃。

## 布局与验收边界

- 检查普通窗口与最小 800×500 窗口：列表仍可用，loading／错误恢复入口可见，长路径与 RequiresReview 证据可展开滚动。
- 当前测试不能替代 OS 视觉、鼠标右键、剪贴板、IME、多显示器、Finder 启动或拖放验收。
- 若截图或系统权限不可用，记录未验收，不扩大屏幕捕获、不绕过权限。
- 手机验证只在用户明确恢复后另行进行；保留首次三星上传超时的历史 UnknownOutcome，不据目录计数一致推断无副作用。
